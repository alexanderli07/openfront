# Compact persisted match history

User approved the proposed separation of full-match compact history from bounded recent debug details, periodic IndexedDB saves and separate summary/detail exports.

Implement a recorder independent of strategy inputs: compact actual command outcomes with their explanations; delta infrastructure changes; count and time-range repeated holds/errors; omit getters, embargo bookkeeping and warship movement detail. Preserve complete meaningful history in the compact export rather than evicting it with debug chatter. Persist by game/player identity every five seconds. Merge buffered events safely when restoring after refresh; serialize storage operations; flush old recorders on bot replacement. Storage failures must be visible in summary export and must not affect gameplay. Use memory-only unique sessions when game identity is unavailable. Existing detailed trace and replay remain available.

Add two ordinary action buttons, Match summary and Detailed trace. Export compact JSON for the summary and existing full debug JSON for detail. Saved latest match remains exportable before a bot is reattached. Tests cover noise floods, command ancestry, repeated holds, infrastructure deltas, refresh restore, interleaved save/load, storage failures and button behavior. Run existing full suite, scenarios, audit/syntax and build freshness. No game strategy changes.

Completed in 1.84.53. The summary does not retain routine getter/candidate detail or individual warship movement; full meaningful command outcomes and infrastructure deltas are independent of the debug ring. Repeated plan/hold/error counts have tick ranges. Local storage is keyed by game/player; missing identity or database failure is visible and preserves a memory export. Existing unsupported saved formats are never overwritten. Autosave every five seconds and best-effort visibility/pagehide flush cannot guarantee the final unsaved seconds on crash; browser clearing/eviction can remove stored histories. Detailed traces remain bounded and memory-only.

Validation: 1,708 tests pass; 23 strategy scenarios, zero unexpected outcomes; generated syntax, gateway audit and build freshness pass. Review findings about failed-command metadata and schema preservation were reproduced and fixed, along with refresh loss/duplicate-building cases. One previous 43,217,566-byte / 5,000-record snapshot produced a 4,240-byte compact summary in the offline check; that snapshot is a short window, not a whole-game size guarantee.
